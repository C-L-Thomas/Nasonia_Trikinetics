Monitor file format

This first version expects a standard DAM text file: recording number, date and time in columns 1–3, with 32 activity channels starting at column 11. Adjust the activity column if your export differs. Only normal activity records (status 1, Ct) are loaded; monitor status/event rows are skipped. Dates such as 21 Aug 26, 21/08/2026 and 2026-08-21 are supported.

3 · Loaded data

Summary per animal within its metadata date window. No death detection or lifespan analysis is performed in this version. End time means the last loaded recording.

Works without installing R. For folders, use a current Chrome or Edge browser on Mac or Windows; individual file selection is also available.
