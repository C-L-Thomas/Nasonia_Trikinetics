Monitor file format

Standard DAM text files are expected: recording number, date and time in columns 1–3, with 32 activity channels starting at column 11. Adjust the activity column if your export differs. Only normal activity records (status 1, Ct) are loaded; monitor status/event rows are skipped. Dates such as 21 Aug 26, 21/08/2026 and 2026-08-21 are supported.

3 · Loaded data

Summary per animal within its metadata date window. End time means the last loaded recording. Continue to the next page to generate lifespan curves.

Lifespan curves

Generate Kaplan–Meier curves for your selected factor. Time is measured from each animal’s metadata start date.

Animal results

All loaded animals are included automatically. A recording gap resets the inactivity confirmation period; missing observations are not treated as zero activity. No exclusion controls are used.
