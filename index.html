Monitor file format

Standard DAM text files are expected, with recording number, date and time in columns 1–3 and 32 activity channels starting at column 11. Adjust the activity column if your export differs. Only normal activity records (status 1, Ct) are loaded. Monitor status/event rows are skipped. Supported dates include 21 Aug 26, 21/08/2026 and 2026-08-21.

3 · Loaded data

Summary per animal within its metadata date window. End time means the last loaded recording. Continue to the next page to generate lifespan curves.

Lifespan curves

Generate Kaplan–Meier curves for your selected factor. Time is measured from each animal’s metadata start date.

Death is inferred at the start of the first uninterrupted recorded period with zero beam crossings for the chosen duration. Any later movement is ignored. Animals without a confirmed death are censored at their last recording. This rule differs from the rolling low-activity method in the R app.

Animal results

All loaded animals are included automatically. A recording gap resets the inactivity confirmation period; missing observations are not treated as zero activity.
