Settings & portable setup

Save settings onto your USB after editing. Include that JSON file when choosing your folder on another computer. Browser storage alone does not travel with the USB.

Only the latest seven days of each file are assessed. Channels with movement in that window are alive unless followed by a continuous zero-activity period of 24 hours (or your chosen threshold). Recording gaps reset that period. Channels with no movement in the week are shown separately and excluded from alive/dead counts.

How to use this USB app

Keep this HTML file on the USB. Open it in your browser on Mac or Windows, choose the data folder and allow the files to load. Select the folder again after each weekly update. Click a channel to exclude it if empty. The latest seven days are assessed automatically.

Connection labels use status 1 (recording) and 51 (offline), matching your examples. Other status codes are displayed explicitly. All-zero rows with offline codes are excluded from survival calculations.

Environment measurements use the TriKinetics DEnM data sheet: channel 7 temperature × 0.1 °C, channel 12 relative humidity %, and channel 2 light lux. You can adjust the mapping in Settings. Columns count from 1 in the original tab-separated file. The four-value sensor groups are not automatically interpreted as four separate sensors.
